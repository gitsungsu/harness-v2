# slugify — PRD

## 1. 개요

문장을 URL에 쓰는 슬러그로 바꾸는 명령줄 도구.

## 2. 기술 스택

- Python, uv. 표준 라이브러리만 사용한다 (외부 의존성 없음). 테스트는 pytest.
- 패키지는 `src/` 레이아웃, 실행 진입점은 `pyproject.toml`의 `[project.scripts]`로 등록한다.

## 3. 요구사항

- 명령: `slugify "<문장>"` (진입점 이름 `slugify`). 결과를 한 줄로 표준 출력에 낸다.
- 규칙: 소문자로 바꾼다 → 영문 소문자·숫자가 아닌 문자 덩어리는 `-` 하나로 바꾼다 → 앞뒤의 `-`를 지운다.
  - `"Hello, World!"` → `hello-world`
  - `"  a  b  "` → `a-b`
  - `"C++ & Rust"` → `c-rust`
- 결과가 빈 문자열이면(예: `"!!!"`) 아무것도 출력하지 않고 표준 오류에 한 줄 이상 메시지를 낸 뒤 종료 코드 1로 끝난다.
- 인자가 없으면 종료 코드 2.

## 4. 범위 밖

- 유니코드 음역(한글 → 로마자), 길이 제한, 파일 입력.
