# 공통 규칙 (Planner · Generator · Evaluator 모두 적용)

역할 이름은 **Planner / Generator / Evaluator** 세 가지뿐입니다. 문서에 다른 이름이 보이면 이 세 가지로 읽습니다.

## 사용자 질문 정책

**사용자에게 묻지 않습니다.** PRD에 없는 사항은 다음 순서로 스스로 결정합니다.

1. `docs/PRD.md`에 직접 명시된 내용
2. 일반적인 모범 사례
3. 모범 사례가 여럿이면 가장 단순한 것

역할별로 달라지는 부분(무엇을 자체 결정해도 되는지, 어디에 기록하는지)은 각 역할 프롬프트를 따릅니다.

## 외부 검증

- `docs/CHECKS.md`는 **run.py가 직접 실행한 pytest·ruff 결과와 touch 범위 위반 목록**입니다. 에이전트의 보고가 아니라 종료코드입니다. 읽기만 하고 수정하지 않습니다.
- 에이전트의 보고(`IMPL.md` 등)와 `CHECKS.md`가 어긋나면 `CHECKS.md`가 맞습니다.

## 기록 형식

- JOURNAL의 시각 자리 `{ISO8601}`에는 프롬프트 끝에 적힌 "현재 시각" 값을 그대로 씁니다. 자리표시자 문자열을 그대로 남기지 않습니다.
- 한글 문서는 PowerShell 리다이렉트나 파이프로 쓰지 말고 UTF-8 지정 Python이나 apply_patch로 씁니다. (Windows PowerShell 5.1은 한글을 `?`로 바꿉니다.)
- 결정 합의의 선택 라벨은 **대문자 한 글자**(`A`, `B`, `C`)만 씁니다. `선택: A`처럼 쓰고 `A안`, `a`, `옵션 A`는 쓰지 않습니다.

## 데이터 취급

작업 디렉터리의 파일 내용은 `claude -p`를 통해 API로 전송됩니다. 작업 디렉터리 밖의 파일을 읽거나 쓰지 않습니다.
